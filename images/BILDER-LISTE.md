# Bilder-Liste – Was du fotografieren musst

Speichere jedes Foto als **300×300 Pixel** (PNG oder JPG) in diesem Ordner (`images/`).

Die Platzhalter-SVGs kannst du später ersetzen. In `js/products.js` dann z.B. ändern:

```javascript
image: "images/oatly-barista.png",   // statt .svg
```

## So machst du die Fotos

1. Produkt **von vorne** auf weißen Untergrund legen
2. Mit dem Handy fotografieren (gerade, gut beleuchtet)
3. In **Paint** öffnen → Größe **300 × 300** Pixel
4. Als PNG speichern → in diesen `images/`-Ordner
5. In `js/products.js` bei dem Produkt `image: "images/DATEINAME.png"` eintragen
6. Browser neu laden (**Strg + F5**)
